# Agent 文档设计

用于创建或审查 Skill、`AGENTS.md`、`CLAUDE.md` 和它们指向的参考文档。只在这些
文档发生变化时读取。

## 触发指针

描述和链接必须同时说明“这是什么”与“哪些真实任务分支需要读取它”。一个分支只写
一个触发，不堆同义词；必须执行的规则不能藏在不会触发的弱链接后面。

## 信息层级

1. 每次运行都需要的动作留在主流程。
2. 当前文件内只保留完成动作所需的短参考。
3. 只服务部分分支的知识放到独立参考，由精确指针按需加载。

步骤与它的定义、边界和完成标准放在一起。父路由不复制专家方法；同一含义只保留
一个事实源。

## 完成标准

每个非平凡步骤都要有可检查且覆盖完整范围的完成条件。先把边界写清；只有真实观察
到后续步骤诱发草率完成时，才把长序列拆成独立阶段或上下文。

## 精简审计

- 环境、配置、目录结构或 `--help` 一条命令就能提供的事实留在环境中，文档只记录
  难以发现的约定、原因和故障边界。
- 删除不会改变 Agent 默认行为的空泛指令；用明确动作和完成信号替代“认真”“全面”。
- 优先使用已有且含义稳定的短概念作为统一术语，不重复铺陈同一规则。
- 修改后逐行检查相关性，删除过期分支和重复解释。
