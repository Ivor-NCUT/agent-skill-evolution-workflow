# Skill 达尔文进化

1. 定位本轮实际使用的主要 Skill，不把反馈写进无关 Skill。
2. 保存基线、反馈原话和能复现问题的最小用例。
3. 调用已安装的达尔文 Skill 生成最小候选改动。
4. 对比基线与候选；没有改善或造成回退时丢弃候选。
5. 更新版本、测试、来源和 `company-skills.json`，再进入验证交付。

没有明确反馈或可验证目标时不做“自我进化”表演。
