# Skill 达尔文进化

1. 定位本轮实际使用的主要 Skill，不把反馈写进无关 Skill。
2. 保存基线、反馈原话和能复现问题的最小用例。
3. 调用已安装的达尔文 Skill，按本次目标选择最小修复或实测评估；不把完整 benchmark、评分卡或逐个批准变成所有迭代的必经门槛。
4. 用相关用例对比基线与候选；区分静态检查、模拟推演与真实模型运行，未实测不声称效果提升。发现回退则只撤销本轮改动，保护原有未提交内容。
5. 同步确实变化的版本、路由用例和来源；安装／发布状态实际变化才更新 `company-skills.json`，保留用户已有变更。仅进入用户要求的验证与交付范围。

没有明确反馈或可验证目标时不做“自我进化”表演。
