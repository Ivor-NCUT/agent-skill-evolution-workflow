# Skill 创建归类

1. 描述真实触发语、重复频率、输入和可指认输出。
2. 搜索 `company-skills.json` 和已安装 Skill；已有能力则复用或补路由。
3. 单一输出契约用普通 Skill；三个以上独立能力或共享知识明显时才用 MOE。
4. 归入全栈开发、社媒运营、课程制作人、Skill 进化之一；平台连接器保留共享工具。
5. 记录角色类型、来源、许可、仓库、版本和旧入口兼容关系。

输出归类结论和最小下一步，不自动创建仓库。
