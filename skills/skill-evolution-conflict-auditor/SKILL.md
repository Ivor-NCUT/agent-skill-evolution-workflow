# Skill 冲突审计

1. 比较 frontmatter 触发语、输入、输出和禁止事项。
2. 区分可调和重叠、必须隔离的业务差异和纯重复实现。
3. 用一个稳定 tie-breaker 解决相邻边界；相同能力保留一个事实源。
4. 检查父路由是否复制专家方法或两个父路由竞争。
5. 输出冲突表、裁决、兼容影响和需要更新的路由用例。

不因名称相似就合并，不因来源不同就复制同一规则。
